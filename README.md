# Эйфория — карточка салона и заявки

Страница записи салона «Эйфория» (Реутов), материалы для Яндекс Бизнеса и сервер заявок с ботом в Telegram.

- `server/` — то, что работает в салоне: `server.py` (страница, заявки, бот, отчёт), `public/index.html` (собранная страница), `manifest.json` (версия для обновления).
- `gen_data.py` → `data.json` — прайс и тексты; `template.html` — страница; `build.py` — сборка всего комплекта в `dist/`.
- `ИНСТРУКЦИЯ.txt` — запуск и перенос в Яндекс Карты.

## Как выходит обновление

1. Правки в исходниках → `python3 build.py "что изменилось"` (обновляет `server/public/index.html` и `server/manifest.json`).
2. Коммит и пуш в `main`.
3. Серверы салона сами подтягивают новую версию (раз в 5 минут или по `/update` в боте) и перезапускаются.

`config.json` и `leads.db` живут только на сервере и в репозиторий не попадают.
